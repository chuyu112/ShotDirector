# 镜导空白净包清单

## 分层

- `app/`、`scripts/`、`worker/`：通用程序逻辑。
- `config/workflow-rules.json`：与具体作品无关的审核、连续性、模型和分镜图规范。
- `project-data/templates/`：可替换的项目背景、世界观和最终美术风格；模板不自动成为程序默认值。
- `docs/`：交接手册、PRD 和数据边界说明。

## 已清除

- 历史漫画页、漫画拆解草稿和画格截图。
- 历史分镜脚本、项目镜头数据和旧项目迁移规则。
- 人物、道具、场景参考图和生成结果。
- LibTV 画布状态、白模导出、拉片结果和 GPT 任务响应。
- 浏览器中的历史 localStorage、sessionStorage 和分镜图 IndexedDB；首次打开保存的是通用空白状态。
- 构建缓存、运行日志和临时迁移快照。

## 未包含

- `node_modules/`：在新电脑执行 `npm install` 重建。
- `.git/`、构建产物和运行时目录。
- 工作区外的原始漫画、视频、图片及用户个人文件。

## 保留的项目模板

`project-data/templates/city-hunter-showa60.json` 仅保存《城市猎人》真人项目的背景、世界观、声音约束和最终美术风格，不包含任何一话的剧情、镜头、人物资产或生成内容。
