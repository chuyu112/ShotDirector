# 漫镜接入本机 Codex GPT-6

线上漫镜增加「本地 Codex GPT-6」选项，可在 Chat / Work 和独立严格审核中分别选择。通过这台 Mac 的 Codex ChatGPT 登录额度调用 `gpt-6-astra`，支持文字和图片。模型在云端运行；Mac 负责连接和执行任务，需保持登录、联网和唤醒。已有 API 配置与默认选择保留。

## 调用路径

浏览器 → 已认证的漫镜 Gateway → 当前账户及项目的 Worker → Pi Harness → 本地 Codex 中继 → Mac 连接服务 → Codex app-server → 完整结果按原任务返回。

- Gateway 的 `MANJING_LOCAL_CODEX_OWNER_ID` 绑定一个 `users.id`；只有该账户的 Worker 收到这个模型。主连接令牌不进入 Worker，项目专用 HMAC 令牌不进入浏览器。
- Mac 主动访问服务器 HTTPS，不开放本机公网端口。服务器不安装 Codex、不持有 Mac 的 ChatGPT 登录凭据。
- 完整提示词、Chat、严格审核保持 MAX；诊断允许 low。每次调用为全新的临时模型会话，只接收任务文本及当前项目内的图片，关闭工具、MCP、命令、文件修改和子 Agent。
- Reviewer 仍经现有独立 Harness Session / Run，只返回问题、证据及建议；修改提示词后原审核过期，不能自动批准。
- 领取前持久化任务状态，本机执行前写入接收记录。网关或本机重启不重新运行已领取任务。仅完整 JSON 与完成事件能作为结果；中断保留失败状态，不自动换模型或重试生成。
- 本地中继结果在服务器保留 24 小时，已有业务产物仍按项目保存。本机保留执行记录以防重放，临时图片在执行结束后清除。

## 配置与启动

服务器 `.env.server` 增加以下变量（示例文件没有真实凭据）：

```dotenv
MANJING_LOCAL_CODEX_OWNER_ID=<users.id>
MANJING_LOCAL_CODEX_TOKEN=<随机至少32字符的独立连接令牌>
MANJING_LOCAL_CODEX_RELAY_URL=http://127.0.0.1:8080/api/local-codex
```

在 Mac 私有文件 `~/Library/Application Support/Manjing/local-codex/connection.json` 保存站点、相同令牌和账户 ID，文件权限为 600：

```json
{"server":"https://manjing.kakayiduo.cloud","token":"<连接令牌>","ownerId":"<users.id>"}
```

在项目目录执行：

```sh
npm run check:local-codex
node deploy/install-local-codex-launch-agent.mjs
```

检查命令只验证本机登录、GPT-6 图片/MAX 能力和额度，不发起模型生成。安装器将三个运行文件复制到私有目录，并注册当前用户 LaunchAgent `cloud.kakayiduo.manjing-local-codex`，登录后自动连接。配置、日志和执行记录均在上述私有目录，独立于工作区分支。临时手动运行可用 `npm run start:local-codex`，不要与 LaunchAgent 同时运行。

```sh
launchctl print gui/$(id -u)/cloud.kakayiduo.manjing-local-codex
# 停用连接服务
launchctl bootout gui/$(id -u)/cloud.kakayiduo.manjing-local-codex
```

离线状态在约 20 秒内反映至服务器，再随页面健康轮询刷新。额度用尽、模型不可用或退出登录会显示未就绪；只有用户主动切换时才使用 API。重连后自动补传已经完成的结果，执行状态不明时需要查看原任务。

## 验证记录

开发中已完成一次直接 Codex GPT-6 MAX 图片调用：128×128 合成绿色图，收到完整 JSON `{"ok":true,"color":"green"}`。此结果只证明本机模型与图片输入，不代表公网链路或正式漫画内容已验收。

自动回归包含账户/项目隔离、真实 Gateway 与 Worker 的 Harness 路由、图片路径限制、完整结果回传、令牌隔离、重复任务、重启中断、离线状态和隐私输出。最终测试、发布及公网验证结果在本次结束后补充。

协议依据：[Codex app-server 官方文档](https://learn.chatgpt.com/docs/app-server)，以本机 `0.154.0-alpha.6.2` 的模型目录和 JSON Schema 实测为准。当前使用权限配置 `permissions`；任务继承线程权限，不在 `turn/start` 重复覆盖。响应中的模型记录为执行选择，未由上游单独报告的实际模型保持空值。
