# 七项 TypeScript 错误修复（本地）

## 修复内容

| 原错误 | 修复 |
| --- | --- |
| 主页面审核恢复：可选提示词在回调内失去字符串收窄 | 捕获当前提示词常量，通过非空检查后用于审核版本计算；保留原文，不提供空字符串替代 |
| 全局文件列表：`some` 回调参数隐式 `any` | 将经过现有条目校验的列表显式定义为 `GlobalFileSummary[]` |
| 白模运行时：`useRef` 缺少初始值；销毁时不能赋 `undefined` | 明确运行时引用允许 `undefined`，并以它初始化，匹配创建与销毁生命周期 |
| Worker/DB：`cloudflare:workers`、`Fetcher`、`D1Database` 类型缺失 | 固定官方 Workers 类型依赖，局部导入 D1 类型并声明实际使用的可选 DB 绑定；资产绑定从 Vinext 实际入口契约推导，适配器保持 Promise 返回 |

Workers 类型局部引用，避免其全局 Request/Response 声明覆盖浏览器 DOM 类型。没有使用 `any`、忽略报错注释、关闭严格检查或排除业务文件来消除错误。DB 未绑定时仍由原有运行时检查报错。
